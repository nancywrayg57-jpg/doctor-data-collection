## 决策

1. `work/generate_obsidian_profiles.py` 升级为统一总底表生成入口，默认优先读取 CSV，也支持读取 XLSX。
2. 脚本按 `医院` 字段自动创建医院目录，并为每位医生生成一个 Markdown 画像文件。
3. 每家参与生成的医院都生成 `_索引.md`，索引内保留画像链接、科室、职称、重点优先级、重点关注范围、异常提示和官网来源。
4. 中山大学附属第五医院已有医生画像，本轮按默认规则整院跳过，不改写其任何既有 Markdown。
5. 医生画像内容只来自统一总底表字段，主要映射为：
   - 科室：`科室`、`科室_分类页`、`科室_列表卡片`
   - 职称：`职称`、`职称身份原文`、`职称_关键词`
   - 简介/擅长：`简介/擅长`、`擅长诊疗方向摘录`、`列表简介`
   - 重点信息：`重点关注范围`、`重点疾病标签`、`亮眼经历线索`、`异常提示`
   - 来源信息：`来源类型`、`来源链接`、`采集日期`、`复核状态`
6. 默认不覆盖没有自动生成标记的既有医生 Markdown；只有带本脚本自动生成标记的文件才会在重复运行时刷新。管理员明确授权时可使用 `--admin-allow-overwrite`。
7. 脚本不改总底表。若发现 `姓名` 字段异常过长，只在生成报告中提示，并用截断文件名避免 Windows 路径超限。
8. 全量生成报告固定输出到 `医生画像仓库/99_资料来源/珠三角三甲医院_Obsidian画像全量生成报告.md`，包含总医生数、成功生成数、跳过数、按医院统计、异常提示清单、未生成原因和生成过程质量提示。
