# 2026-08-10 医生详情正文页面噪声过滤

## 目标

修复自动采集脚本把面包屑、页头导航、页尾、侧栏、分页、分享控件和“加载更多”等页面无关信息写入医生详情字段的问题，同时保留面包屑对科室识别的辅助价值。

## 根因

通用适配器此前会从 `.content`、`.main` 等较大容器直接提取全部可见文字。部分医院官网把面包屑和正文放在同一容器内，导致导航文字进入 `详情正文摘录`，并继续参与擅长、重点标签和亮眼经历计算。

## 决策与实现

1. 在解析详情页时先独立提取导航上下文，仅用于科室识别。
2. 正文提取前从 DOM 中移除导航、页尾、侧栏、分页、分享、隐藏元素和交互控件。
3. 增加文本级兜底过滤，处理没有规范 HTML 类名的“当前位置：首页 > ...”和“面包屑 首页 / ...”前缀。
4. 页面导航不会进入简介、擅长、标签或亮眼经历；官网缺失内容仍按项目规则留空。
5. 相同 DOM 过滤逻辑同时用于通用模板、中山眼科中心专用适配器和南部战区空军医院专用适配器。
6. 本次不修改或清洗统一总底表中的既有正式记录，只保证修复后的新采集结果不再写入该类页面噪声。

## 验证结果

1. Python 语法检查通过。
2. 3 个页面噪声过滤回归测试全部通过：标准面包屑、页头页尾与交互控件、无标准类名的面包屑前缀。
3. 中山大学肿瘤防治中心官网真实医生页 `https://www.sysucc.org.cn/node/3768`：姓名、科室、职称和擅长正常，正文及擅长中无面包屑或导航词。
4. 中山大学附属第三医院官网真实医生页 `https://www.zssy.com.cn/node/15372`：核心字段可解析，正文无页面导航词。
5. 中山大学中山眼科中心官网真实医生页 `http://www.gzzoc.org.cn/node/12767`：专用适配器核心字段正常，正文无页面导航词。
6. 南部战区空军医院官网真实医生页 `http://www.nbkjyy.mil.cn/expert/127.html`：专用适配器核心字段正常，正文无页面导航词。
7. 验证过程只读取官方公开页面，未运行正式追加，统一总底表未修改。
