### 6. 追加后检查

正式追加后检查：

1. 输出 mode 是否为 master_append。
2. new_rows_added 是否大于 0，除非该医院此前已追加。
3. master_rows 是否与总底表当前医生总数一致。
4. duplicate_skipped 或重复跳过数是否合理。
5. detail_errors 是否异常升高。
6. 总底表 XLSX、CSV 和更新报告修改时间是否更新。
7. 医院统计中是否出现目标医院。
8. 目标医院异常提示数是多少。
9. GitHub 登录身份是否允许执行 Codex developer 推送；不是 `xtzhou247` 时仅记录本地结果。

如果单家医院医生数超过 700，使用更长等待时间或监控进程。不得在未确认进程完成前重复启动正式追加。
